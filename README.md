# Overview
The following repo contains a Jupyter notebook used to prepare the files used in the Tableau dashboard published here. 

The pertinent data files are not stored in this repo as they exceed GitHub's storage limits. The required files and their names are [series_data.tsv] (https://download.bls.gov/pub/time.series/la/la.series), [state_level_data.tsv](https://download.bls.gov/pub/time.series/la/la.data.2.AllStatesU), [county_level_data.tsv](https://download.bls.gov/pub/time.series/la/la.data.64.County). Clicking each link should take you to the appropriate file to download. Ensure you rename each file appropriately and place them in a directory titled 'downloaded_data'

# Data and Analysis
This project features United State unemployment rate data at the state and county level, collected between January 1, 2019 - December 31, 2023. An analysis of the data highlighting trends may be found within the word document, Unemployment_dashboard_analysis, in this repo.
